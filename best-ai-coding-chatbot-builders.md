- **Solo indie dev:** Replit Agent (browser-native shipping) → v0 (frontend/Next.js) → OpenAI Codex (own the workflow).

- **Enterprise:** GitHub Copilot (breadth), Tabnine (privacy/governance), Sourcegraph Cody (complex codebases), Amazon Q (AWS-heavy).
- **Students:** GitHub Copilot Student (free) + Replit Starter; Bolt or v0 for portfolio apps.
